# Languages (i18n)

`i18n.py` (#263, #265). Polish words and style: `translations/pl/GLOSSARY.md`; English domain terms: `CONTEXT.md`.

## Resolving the language

A request's language is chosen in this order:
1. a valid `lang` cookie;
2. the best `Accept-Language` match by base language (`pl-PL` → `pl`);
3. `DEFAULT_LANGUAGE`.

Resolving it never raises, error pages included. Only `POST /language` sets the cookie.

Pages rendered from a template get `Content-Language` and `Vary: Accept-Language, Cookie`. `<html lang>` and `og:locale` follow the language; there is no `hreflang`. No URL carries a language, and share links carry none either: the recipient gets their own.

JSON errors that the web UI may show, and so carry a `code` (root `CLAUDE.md`, Invariants), are those of `/upload`, `POST /api/token` and the 413/429/404/500 handlers; `code` sits next to `error` (#285). Browser code maps `code` to its own message, with a generic fallback, and never displays `error`.

## Catalogs

Flask-Babel with one `messages` domain. The English source text is the msgid, so there is no `en` catalog.

`translations/messages.pot` and `translations/<lang>/LC_MESSAGES/messages.{po,mo}` are committed and regenerated by `python translations/catalogs.py`. Extraction is configured in `babel.cfg`: root `*.py` and templates, `ext.i18n.trimmed`, `# Translators:` comments.

## Writing translatable text

- **Translate through `i18n`, never `flask_babel` directly.**
  - Python: `from i18n import gettext as _`.
  - Templates: `_()` or `{% trans %}`, with one block per paragraph, inline markup kept in the msgid and attribute values as `%(name)s`.
  - For `pl`, `i18n` joins one-letter words (a, i, o, u, w, z) to the next word with a non-breaking space; translators never type one.
- **Page scripts hold no text (#265, #286).**
  - What JS writes comes from the page's `page-strings-json` island, rendered from `templates/_<name>_strings.html` partials and read through `lib/strings.js` (see `static/js/CLAUDE.md` §Text).
  - Import the partials `with context`. A context-free import is cached across languages.
  - Plurals for a count known only in the browser are `plural_forms(singular, plural)`: CLDR category → gettext form, extracted like `ngettext`.
  - `tests/js/js-literals.test.js` checks the converted modules.
- **`flash(_('…'))` is eager.** Use `i18n.lazy_gettext` only for module constants, and `str()` them before flashing. `tests/unit/test_i18n.py` enforces this.

## Language menu

#287; `templates/_language_menu.html`, script `static/js/pages/language-menu/`.

- It sits in the header before Login/Logout: a `<details>` menu button (globe + code) listing every language in `LANGUAGES` by its native name (`i18n.native_name`).
- Each item is a `POST /language` form with `next` set to the current page (home for a page from a POST-only route), so the menu works without JS.
- `language_processor` passes `language_menu` (`i18n.language_menu`). It is None on `RECIPIENT_ENDPOINTS` (`view_file` and `confirm_view_file`, so the "drop is gone" page too) and when there is a single language.
- Names and code are `translate="no"`, which the pseudo-locale check skips.

`/language` (POST) remembers the choice.
- It is CSRF-gated, with no `Authorization` exemption.
- `lang` must be in `LANGUAGES`, and `next` must be a local path (else `/`).
- It sets the `lang` cookie (1 year, `SameSite=Lax`, `HttpOnly`, `Secure` following `SESSION_COOKIE_SECURE`) and answers `303` to `next`. A refused request sets nothing.

## Tests

`tests/unit/test_translations.py` checks:
- `.pot`/`.po`/`.mo` drift;
- strict completeness: an untranslated or fuzzy entry fails;
- no obsolete entries;
- placeholder and inline-tag parity;
- the pseudo-locale `xx`. Each page in its `CONVERTED_PAGES` is rendered with every translation wrapped in markers; visible text or `aria-label`/`title`/`placeholder`/`alt` outside them fails.

When you translate a page:
- add it to `CONVERTED_PAGES`;
- add its modules to `CONVERTED_MODULES` in `tests/js/js-literals.test.js`.

Existing tests stay English (`DEFAULT_LANGUAGE=en`). Polish gets one DOM fixture (`<template>--<state>.pl`) and a smoke test per page.
